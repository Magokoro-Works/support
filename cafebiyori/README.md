# ☕ カフェ日和 サポート

訪れたカフェの雰囲気や使いやすさを、自分の基準で残せるカフェ記録アプリです。

## 主な機能

- 訪問したカフェの記録(写真・評価・訪問履歴・メモ)
- 行きたいカフェのストック(参考画像・メモ・参考URL)
- MAPでカフェを探して「行きたい」に保存、訪問後はワンタップで訪問記録へ
- お気に入り管理・検索・並び替え

## よくある質問

**Q. データはどこに保存されますか?**
A. すべて端末内にのみ保存されます。外部サーバーへの送信はありません。詳しくは[プライバシーポリシー](./PRIVACY.md)をご覧ください。

**Q. 機種変更でデータは引き継げますか?**
A. 現在のバージョンではデータ移行・バックアップ機能はありません。端末の変更・アプリの削除でデータは失われますのでご注意ください(今後のアップデートで対応予定です)。

**Q. 位置情報はいつ使われますか?**
A. 住所入力の「現在地を取得」を押したときだけ、その場で一度だけ使用します。追跡は行いません。
